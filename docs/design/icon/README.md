# Key Doctor icon

A key whose bow is a medical cross: key plus doctor in one shape. 24 grid, 2px round stroke, one color, teal `#0F5F5C` (dark theme `#7CD4CF`).

| File | Use |
|---|---|
| `logo.svg` | The mark, `currentColor`. Header tile (24px on a 32px teal tile, stroke 2.2) and inline icons. |
| `favicon.svg` | 32px teal tile with a solid bow so it stays readable at 16px. |
| `app-icon.svg`, `app-icon-512.png` | Full-bleed square for the Telegram bot avatar (Telegram crops it to a circle) and app icons. |

Sizes, both themes and two alternatives are on the design canvas board "Key Doctor · icon (cross key)".
